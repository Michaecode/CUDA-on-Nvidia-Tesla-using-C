# Tesla K20Xm CUDA Lab

Experimental CUDA/HPC environment built around an NVIDIA Tesla K20Xm
passed through to a Rocky Linux 8 VM running on Proxmox.

## Hardware

- NVIDIA Tesla K20Xm
- 5700 MiB VRAM
- Compute Capability 3.5

## Software

- Proxmox VE
- Rocky Linux 8
- NVIDIA Driver 470.256.02
- CUDA 11.4

## Goals

- Learn CUDA programming
- Experiment with GPU parallel computing
- Compare CPU vs GPU performance
- Experiment with numerical algorithms
- Benchmark the Tesla K20Xm
